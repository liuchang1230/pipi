# pipi

Desktop AI app fully compatible with pi agent and its extensions.

## Features

- Electron + Vite + React desktop app
- Integrated terminal (xterm + node-pty)
- SSH / SFTP remote session support
- Markdown rendering with syntax highlighting
- Project & session management
- Custom terminal themes

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Scripts

| Script            | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start dev server         |
| `npm run build`   | Build for production     |
| `npm run preview` | Preview production build |
| `npm run typecheck` | Type-check all sources |
